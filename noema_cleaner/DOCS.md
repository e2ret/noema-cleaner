# NOEMA Cleaner

## Первый запуск

1. Отключите Protection mode на странице приложения. Без него нет доступа к Docker, и работает только очистка `/config`.
2. Запустите приложение и включите «Показывать в боковой панели».
3. Откройте панель Cleaner: сканирование начнётся само.

## Права и безопасность

Приложению нужны широкие права (доступ к Docker, запись в `/config`), поэтому у него низкий рейтинг безопасности. Подробное объяснение, что запрашивается и что удаляется: https://github.com/e2ret/noema-cleaner#права-и-безопасность. Cleaner не перезапускает другие приложения.

## Уровни пунктов

- **safe** — пересоздаётся само. Только такие пункты удаляются автоочисткой и кнопкой в HA.
- **caution** — есть последствия (сжатие базы с удалением старой истории, удаление образов). Удаляются только вручную из панели.

## Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `auto_clean` | `false` | Автоматически чистить безопасное |
| `interval_hours` | `168` | Период автоочистки, часов |
| `log_max_age_days` | `7` | Возраст логов Zigbee2MQTT для удаления, дней |
| `keep_esphome_versions` | `1` | Сколько последних версий ESPHome оставлять |
| `mqtt` | `true` | Публиковать сущности в HA через MQTT |
| `scan_interval_minutes` | `60` | Период сканирования, минут |

## Сущности MQTT

«Можно освободить», «Свободно на диске», «Заполнение диска», «Освобождено при последней очистке», «Рост занятого места за сутки», «Последнее сканирование», «Выполняется», кнопки «Очистить безопасное» и «Пересканировать».

Нужен брокер Mosquitto и интеграция MQTT.

## Обновление

Магазин приложений → ⋮ → «Проверить обновления» → «Обновить». Не используйте «Пересобрать»: он не применяет изменения манифеста.
