Только для информации, отсюда ничего не удаляется. Образ — сама программа, он исчезает при удалении приложения. /data — рабочие данные приложения: модели, базы, настройки; вручную их не чистите. Слой записи — временные файлы приложения, они сбрасываются при его перезапуске; сам Cleaner приложения не перезапускает.
